# Mobile Game In-App Purchases: A/B Testing

This project analyzes mobile game in-app purchases using A/B testing techniques to understand user behavior and optimize revenue.

## Dataset
- Source: [Kaggle](https://www.kaggle.com/pratyushpuri/mobile-game-in-app-purchases-dataset-2025)
- Contents: User demographics, in-app purchase data, and engagement metrics.

## Project Structure
- `data/` – CSV dataset
- `notebooks/` – Jupyter notebooks for analysis
- `README.md` – Project overview
- `.gitignore` – Files to ignore

## Analysis
- Splitting users into A/B groups
- Measuring conversion rates
- Identifying trends in purchase behavior
- Recommendations for feature or pricing changes

## Technologies Used
- Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
